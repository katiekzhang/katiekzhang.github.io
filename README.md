# katiekzhang.github.io

Personal academic website. Live at [katiezhang.org](https://katiezhang.org).

## File structure

```
/
├── index.html                  # Main page — edit content here
├── css/style.css               # All styles and colour tokens
├── js/theme-toggle.js          # Day/night toggle, moon phase, nav highlighting
├── img/                        # Headshot and other images
│   └── headshot.jpg            # Your photo (add this)
├── files/
│   └── cv.pdf                  # Your CV (add this)
├── CNAME                       # Custom domain
├── robots.txt
└── .github/workflows/deploy.yml
```

## Deployment

Push to `main` — GitHub Actions deploys automatically.
